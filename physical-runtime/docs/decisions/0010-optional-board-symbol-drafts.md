# Optional board symbol drafts

Date: 2026-10-10. Status: accepted for the feature branch; exact-device evidence
and required unified Buildkite gates remain release prerequisites.

An explicitly requested DS-ViRe action may send the admitted reviewed board
context revision to an operator-configured HTTPS service with a private tenant
key. It executes through the mobile shell's Rust/UniFFI transport. The physical
runtime accepts an injected cancellable port; it contains no network client,
provider key, Python interpreter, remote vision fallback or media upload.

The action is absent without service configuration and disabled without current
AR registration, authored placement-bound board context and exact board revision.
The user confirms the physical model/revision and authorizes each request. Raw
media, transforms and inferred component IDs never cross this port. Existing
offline perception, dialogue, measurements and AR remain independent.

DS-ViRe executes only tenant-scoped, server-installed reviewed bindings grounded
in `tokito-app-dataset` file hashes. Visual seeds, incompatible revisions and
unreadable markings cannot become exact identities. The binding records exact
catalog resolution and complete pin coverage; unresolved or mismatched evidence
abstains. Missing parts become SVG/JSON schematic drafts, not 3D package assets
or published native catalog symbols. Automated publication gates are unchanged.

Transport forbids redirects and embedded URL credentials, bounds response bytes
and time, and carries cancellation through UniFFI. Lifecycle stop and registration
loss cancel work; stale results are discarded. Private drafts remain local review
artifacts and cannot alter authored placement, accepted pin evidence, design data,
Cloud realtime or the catalog. The tenant key is stored in Expo SecureStore,
held only in memory by the configured port, and removable from Local models.

Threat checks cover tenant isolation, context mismatch, source/file hash changes,
incomplete pin coverage, publication assertions, duplicate references and bounded
transport. Device checks must cover slow/offline service, cancellation, returning
to the camera, TalkBack and landscape controls. None are claimed passed from host
tests alone.
