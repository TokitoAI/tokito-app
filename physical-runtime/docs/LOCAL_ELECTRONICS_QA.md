# Local electronics quality evidence

The optimized e21f5e9 iQOO release evaluation completed 24 raw answers (12
questions, two rounds) in 50.548 seconds. All failed the spoken-format check.
Independent semantic review found repeated contradictions in both rounds,
including an inductor described using electrostatic charge, a diode described
as amplifying, increasing capacitor impedance with increasing frequency,
series currents described as adding, and ground described as a physical
component location. These are factual failures, not merely formatting issues.

This is failed candidate evidence, not a model accuracy percentage. Runtime
execution, initialization and throughput do not establish factual competence.
Raw instrumentation, prompts, semantic rubrics and sampling remain unchanged.
Its results must not be replaced by abstention to manufacture a passing score.

Production bench answers now return admitted source records or explicit
abstention, including general educational questions. No phrasing can select
unverified generation. Voice preparation no longer eagerly loads Qwen for this
path; local speech, admitted grounding and vision remain independent and
available. Installed models remain accessible to explicit runtime evaluation,
not accepted as technical authority. This safety restriction is not proof that
the underlying candidate model has improved.
