# Integration facts

Tokito Companion remains untouched during runtime bootstrap. It is currently a
read/review/chat/suggestion mobile surface and does not become mobile CAD.

The future boundary is a versioned in-process Android API with capability
discovery, lifecycle, cancellation, and typed observations. Desktop/cloud
transport is not owned here.

**How to apply:** build standalone contract and hardware conformance first. Open
a separate Companion issue only after the Android artifact meets Gate 6.
