# Tokito 0.3.0-beta.1

The first unified Tokito Android beta combines Cloud project review and the
offline physical-intelligence workspace in one application, package, navigation
system, and release train.

## Included

- project-to-bench navigation with capability-aware permissions;
- local-first, revisioned physical sessions and explicitly authorized
  structured Cloud sync;
- embedded CameraX, AR, voice, dialogue, vision, and physical-tool runtimes;
- signature-verified offline model import with bounded storage, atomic
  activation, and one verified rollback;
- Buildkite validation of Rust/UniFFI, mobile, Physical contracts, Physical
  Android, and the standalone-installable unified arm64 APK;
- preserved Companion package identity (`dev.tokito.companion`) and upload-key
  release path.

## Acceptance status

All non-device Buildkite gates must pass before tagging. Exact iQOO camera, AR,
audio, model-performance, thermal, and upgrade-install acceptance is deferred
until the phone is available; this beta does not claim that hardware evidence.
